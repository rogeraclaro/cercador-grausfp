Afegir el mètode `sortBy(col)` just despres de `resetPage()`:

```js
sortBy(col) {
  if (this.sortCol !== col) {
    this.sortCol = col;
    this.sortDir = 1;
  } else {
    if (this.sortDir === 1) this.sortDir = -1;
    else { this.sortCol = ''; this.sortDir = 0; }
  }
  this.resetPage();
},
```

Modificar el getter `filteredRecords` per aplicar l'ordenació DESPRES del filtratge. El getter actual retorna el resultat del `.filter(...)`. Cal embolcallar-lo en una variable `result`, aplicar l'ordre si `sortDir !== 0`, i retornar `result`:

```js
get filteredRecords() {
  const q = this.search.normalize('NFD')
              .replace(/[\u0300-\u036f]/g, '').toLowerCase().trim();
  const result = this.allRecords.filter(r => {
    if (this.hideOld && r.plan_antiguo) return false;
    if (this.filterGrado && r.grado !== this.filterGrado) return false;
    if (this.filterFamilia && r.familia !== this.filterFamilia) return false;
    if (this.filterNivel && r.nivel !== parseInt(this.filterNivel)) return false;
    if (q && !r._normDen.includes(q) && !r._normCod.includes(q)) return false;
    return true;
  });
  if (this.sortDir !== 0) {
    const col = this.sortCol;
    const dir = this.sortDir;
    result.sort((a, b) => {
      const va = (a[col] ?? '').toLowerCase();
      const vb = (b[col] ?? '').toLowerCase();
      return va < vb ? -dir : va > vb ? dir : 0;
    });
  }
  return result;
},
```

IMPORTANT: el getter original retorna directament el `.filter(...)`. Cal substituir-lo exactament per la versió anterior. No canviar res més al bloc de JS.

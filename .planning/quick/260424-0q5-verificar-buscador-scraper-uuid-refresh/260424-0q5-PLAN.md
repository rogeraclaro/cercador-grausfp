del buscador oficial. Cal verificar que tot funciona correctament.

## Diagnòstic actual

- ofertes.json no s'ha regenerat encara amb les noves dades de l'API

## Tasques

### T-01: Renovar BUSCADOR_UUID (acció manual de l'usuari)

**Passos:**
1. Obrir https://www.todofp.es/buscadorgradosfp/buscador al navegador
2. A la consola DevTools, executar:
   ```js
   document.getElementById("formCaptcha").removeAttribute("hidden");
   document.getElementById("formBuscador").setAttribute("hidden","true");
   ```
3. Resoldre el reCAPTCHA que apareix
4. A la consola, el UUID es mostra automàticament — copiar-lo
5. Actualitzar `.env`: `BUSCADOR_UUID=<nou-uuid>`

### T-02: Regenerar ofertes.json via /api/admin/refresh

**Prerequisit:** T-01 completada (UUID vàlid)

Opcions:
- A) Endpoint admin: `curl -H "X-Admin-Token: <ADMIN_TOKEN>" http://localhost:5001/api/admin/refresh`
- B) Directament via Python: `cd fp-cercador/backend && python -c "from scrapers.pipeline import run_pipeline; run_pipeline()"`

**Esperat:** ~12.537 registres (A:8537, B:2786, C:820 + D/E)

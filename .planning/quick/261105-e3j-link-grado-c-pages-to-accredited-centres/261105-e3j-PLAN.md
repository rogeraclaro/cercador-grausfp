# Link Grado C pages to the accredited-centres search

Link each Grado C certificate page `/grau/<ref>` to the accredited-centres search on
centres.grausfp.es (sister project fp-centres-cercador, Phase 5 decision D-07).
No menu entry, no wider integration. Page body stays Spanish; no centre names on the page.

## Known limitation
Link condition uses GrausFP's own centre total; centres site imports daily at 05:00, so for up
to ~1 day a new certificate can land on a zero-results search page. Accepted; no runtime call.

## Component Inventory

All components are hand-coded HTML/CSS. No third-party components.

### Page Shell

```
<body>
  <div class="page-container">
    <header>          — Títol H1
    <section class="filters">  — Search + dropdowns + checkbox + counter
    <main>            — Table + pagination
  </div>
</body>
```

Max content width: 1200px, horizontally centered, padding-inline: 24px.

### Filter Row (D-06)

Single `<div class="filter-row">` containing in order:
1. `<input type="search">` — cerca de text lliure (debounce 250ms)
2. `<select>` Grado — opcions: Tots / A / B / C / D / E
3. `<select>` Família — opcions dinàmiques des del JSON (ordenades alfabèticament) + "Totes" primer
4. `<select>` Nivell — opcions: Tots / 1 / 2 / 3

All controls in a single flex row, wrapping to two rows on viewports below 640px.

### Checkbox + Counter Row (D-06)

`<div class="controls-row">` containing:
- `<label><input type="checkbox" x-model="hideOld" checked> Ocultar pla antic</label>`
- `<span class="counter">` — text: `{N} resultats` (or `1 resultat` if N=1)

### Results Table (D-07)

`<table class="results-table">` with columns in this exact order:

| # | Header | Field | Width |
|---|--------|-------|-------|
| 1 | Denominació | `denominacion` + optional badge | flex (min 300px) |
| 2 | Codi | `codigo` | 120px |
| 3 | Família | `familia` | 200px |
| 4 | Grado | `grado` | 60px |
| 5 | Nivell | `nivel` | 60px |

Observaciones: NOT shown (D-07).

### "Pla antic" Badge (D-08)

Inside the Denominació `<td>`, after the text:

```html
<span class="badge-old">Pla antic</span>
```

CSS: `background: #fef3c7; color: #92400e; font-size: 11px; font-weight: 600; padding: 2px 6px; border-radius: 3px; margin-left: 6px; white-space: nowrap;`

Only appears when `plan_antiguo === true`. Not a row color, not a separate column (D-08).

### Pagination (D-02)

`<nav class="pagination">` containing:
- Botó `Anterior` — disabled on first page
- Up to 7 page number buttons with ellipsis compression:
  - Pattern: `1 … 4 [5] 6 … 47` (current page centered, ellipsis when gap > 1)
  - Always show first and last page number
- Botó `Següent` — disabled on last page
- 50 results per page (constant `PAGE_SIZE = 50`)

Ellipsis rendered as `<span class="pagination-ellipsis">…</span>` (non-interactive).

### Loading State (D-10)

Full-table-area overlay while fetching:

```html
<div class="loading-state">
  <div class="spinner"></div>
  <p>Carregant dades del catàleg FP...</p>
</div>
```

CSS spinner: `border: 3px solid #d1d5db; border-top-color: #2563eb; border-radius: 50%; width: 32px; height: 32px; animation: spin 0.8s linear infinite;`

### 503 Error State (D-11)

Replaces the table area entirely. No retry button.

```html
<div class="error-state">
  <p>⚠️ Les dades del catàleg no estan disponibles. Contacteu l'administrador del sistema.</p>
</div>
```

### Empty State (D-12)

Rendered as a single table row spanning all columns (inside `<tbody>`):

```html
<tr class="empty-row">
  <td colspan="5">Cap resultat coincideix amb els filtres aplicats.</td>
</tr>
```

Visually distinct from 503 error: muted grey text, centered, no icon. The table headers remain visible.

## Interaction Contracts

### Search Debounce (Claude's Discretion)

- Debounce: 250ms after last keystroke before filtering
- Filters both `denominacion` and `codigo` fields simultaneously (SRCH-01)
- Case-insensitive, accent-insensitive (`normalize('NFD').replace(/[\u0300-\u036f]/g, '')`)
- Resets to page 1 on any filter change

### Dropdown Filters

- All three dropdowns filter independently and in combination (SRCH-02, SRCH-03, SRCH-04)
- Família dropdown populated dynamically from unique values in JSON array, sorted alphabetically (SRCH-03)
- Any filter change resets to page 1

### Checkbox (SRCH-05)

- `checked` by default (Alpine.js `x-data` initializes `hideOld: true`)
- When checked: records with `plan_antiguo === true` are excluded from filtered set
- When unchecked: all records (matching other filters) shown, badges appear on old-plan rows

### Pagination (D-02, D-03)

- Only rows for the active page are rendered to DOM (virtual pagination, not CSS hide)
- Page buttons 5-7 visible maximum; ellipsis compresses gaps > 1
- `Anterior` disabled + muted when on page 1; `Següent` disabled + muted on last page
- Clicking a page button scrolls to top of table

### API Constant (D-09)

```js
const API_BASE = 'http://localhost:5000';
```

Declared at top of `<script>` block, before Alpine.js initialization. Single point of change for production deployment.

### Performance Contract (D-03, SRCH-09)

- Single `fetch()` on `DOMContentLoaded` — no subsequent API calls during filtering
- Full JSON array stored in Alpine.js reactive property (`allRecords`)
- Filtering = `.filter()` on `allRecords` in memory — no DOM traversal
- Only `PAGE_SIZE` (50) rows rendered per page — DOM never exceeds ~50 `<tr>` elements
- Family dropdown built once after fetch, before first render

## Accessibility Baseline

- All `<select>` and `<input>` elements have associated `<label>` (explicit `for`/`id` pairing)
- Pagination buttons have `aria-label="Pàgina {N}"` and `aria-current="page"` on active button
- `Anterior` / `Següent` buttons have `aria-disabled="true"` when disabled (not `disabled` attr, to keep focusable)
- Table has `<caption class="sr-only">Resultats del cercador FP Espanya</caption>`
- Error and loading states use `role="status"` for screen reader announcement
- Color contrast: all text on backgrounds meets WCAG AA (4.5:1 minimum)
  - #111827 on #ffffff: 16.8:1 ✓
  - #92400e on #fef3c7: 5.9:1 ✓
  - #6b7280 on #ffffff: 4.6:1 ✓

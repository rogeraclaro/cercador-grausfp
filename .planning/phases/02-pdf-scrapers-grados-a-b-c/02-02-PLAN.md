    ### _download_pdf (Pattern 4 de RESEARCH.md):
    ```python
    def _download_pdf(url: str, timeout: int = 120) -> str:
        """Descarrega PDF a fitxer temporal. Retorna el path. Caller és responsable d'esborrar-lo."""
        # IMPORTANT: Mai usar requests.head() — retorna 403. Sempre GET. (Pitfall 3 RESEARCH.md)
        resp = requests.get(url, headers=HEADERS, timeout=timeout)
        resp.raise_for_status()  # 4xx/5xx → excepció (fail fast D-01)
        with tempfile.NamedTemporaryFile(suffix='.pdf', delete=False) as tmp:
            tmp.write(resp.content)
            return tmp.name
    ```

    ### _write_atomic (Pattern 3 de RESEARCH.md):
    ```python
    def _write_atomic(data: list, output_path: str) -> None:
        """Escriu JSON de manera atòmica: temp file + os.replace() per evitar escriptures parcials."""
        dir_path = os.path.dirname(output_path)
        with tempfile.NamedTemporaryFile(
            mode='w', encoding='utf-8', suffix='.json',
            dir=dir_path, delete=False
        ) as tmp:
            json.dump(data, tmp, ensure_ascii=False, indent=2)
            tmp_path = tmp.name
        os.replace(tmp_path, output_path)  # atòmic en Unix (POSIX rename)
    ```

    ### run() — pipeline principal (D-01, D-02, D-08):
    ```python
    def run() -> dict:
        """
        Executa el pipeline complet per Grados A, B, C.
        Fail fast: si qualsevol Grado falla, l'excepció es propaga i ofertes.json NO s'escriu.
        Retorna resum estructurat per a la Fase 4 (/api/refresh-status).
        """
        start = time.time()
        parsers = {
            'A': (PDF_URLS['A'], parse_grado_a),
            'B': (PDF_URLS['B'], parse_grado_b),
            'C': (PDF_URLS['C'], parse_grado_c),
        }
        all_records = []
        by_grado = {}

        for grado_letter, (url, parser_fn) in parsers.items():
            pdf_path = None
            try:
                pdf_path = _download_pdf(url)
                records = parser_fn(pdf_path)
                for r in records:
                    r['grado'] = grado_letter
                by_grado[grado_letter] = len(records)
                all_records.extend(records)
            finally:
                # D-03: eliminar PDF temporal sempre, fins i tot en error
                if pdf_path and os.path.exists(pdf_path):
                    os.unlink(pdf_path)
            # Si _download_pdf() o parser_fn() fallen: excepció propagada aquí (D-01)
            # ofertes.json NO s'escriu perquè _write_atomic no s'arriba a cridar

        # Afegir id seqüencial (1-based)
        for i, record in enumerate(all_records, start=1):
            record['id'] = i

        _write_atomic(all_records, DATA_PATH)

        return {
            "total": len(all_records),
            "by_grado": by_grado,
            "errors": [],
            "duration_seconds": round(time.time() - start, 2),
        }
    ```

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Internet → requests.get() | Bytes descarregats de todofp.es; pot ser un fitxer no-PDF o resposta maliciosa |
| tempfile → os.replace() | Escriptura intermèdia a fitxer temporal; risc d'interrupció parcial |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-04 | Spoofing | `_download_pdf` — URL dels PDFs pot retornar contingut diferent | mitigate | `resp.raise_for_status()` detecta 4xx/5xx. Si la URL retorna un PDF diferent (redirect silenciós), `pdfplumber.open()` elevarà excepció al parser (fail fast D-01). Verificar `Content-Type: application/pdf` a la resposta afegeix defensa extra (opcional però recomanat). |
| T-02-05 | Denial of Service | `_download_pdf` — timeout de 120s per PDF | accept | Timeout explícit de 120s per evitar bloqueig indefinit. Si el servidor és lent, l'error es propaga i ofertes.json no s'actualitza (D-01). Acceptable per a ús manual/admin. |
| T-02-06 | Tampering | `_write_atomic` — disc ple durant escriptura JSON | mitigate | Escriptura a fitxer temporal al mateix directori que `ofertes.json` + `os.replace()`. Si el disc és ple, `NamedTemporaryFile` elevarà `OSError` i el fitxer original roman intacte. Captura `OSError` al caller si cal missatge d'error més descriptiu. |
| T-02-07 | Information Disclosure | Headers HTTP — User-Agent revela plataforma | accept | El User-Agent és necessari per evitar bloqueig 403. No conté informació confidencial del servidor. Risc baix. |
</threat_model>

Fonts de dades

D'on surt tota la informació que mostra el cercador

Totes les dades del cercador provenen de fonts públiques i oficials de l'Administració General de l'Estat. Cap dada s'introdueix manualment, llevat de les correccions documentades a Errors coneguts a les fonts oficials: el sistema llegeix automàticament les fonts que es descriuen a continuació i les consolida en un únic índex.

El marc de referència és la Llei Orgànica 3/2022, d'ordenació i integració de la Formació Professional, que estableix els Graus A, B, C, D i E i el catàleg de famílies professionals.

Errors coneguts a les fonts oficials

Les fonts oficials també s'equivoquen. Quan dues es contradiuen, comprovem el text del reial decret al BOE i mostrem la xifra del decret. Les d'aquest apartat són les úniques dades del cercador corregides a mà, i cada correcció deixa d'aplicar-se sola si el Ministeri esmena la seva xifra.

Registre Estatal d'Entitats de Formació de la FP

registrosfp.educacion.gob.es

El registre públic dels centres autoritzats per impartir Formació Professional a tot l'Estat.

Font Què se n'obté On es fa servir Com s'obté
Consulta pública d'oferta Centres que imparteixen cada ensenyament (Graus A–E), amb població, província i comunitat autònoma. Panell de centres de cada resultat i seguiment de novetats. API JSON Una petició GET inicial obté la cookie de sessió i després es consulta un endpoint JSON (datosTablaPublico) per a cada ensenyament: unes 1.200 consultes a 1 per segon (~20 min).

Scraping HTML Primer es dedueix del domini del correu del centre; si no n'hi ha, es llegeix l'HTML de la fitxa del centre (centrorcd), amb esperes si el servidor limita les peticions (HTTP 429).

Servei Públic d'Ocupació de Catalunya (SOC)

serveiocupacio.gencat.cat

Font d'àmbit autonòmic: cobreix únicament l'oferta de formació professional per a l'ocupació (FPO) gestionada per la Generalitat de Catalunya. És un sistema diferent de la FP reglada estatal i no inclou cap altra comunitat autònoma.

Font Què se n'obté On es fa servir Com s'obté
Cursos FPO Cursos de formació per a l'ocupació programats a Catalunya: centre, dates, horari, modalitat, estat d'inscripció i enllaç a la fitxa del SOC. Mode «Cursos FPO (Catalunya)» del cercador i panell de detall de cada especialitat. API Algolia El cercador del SOC funciona amb Algolia, un servei de cerca extern. Es recorre l'índex de cursos sencer amb la clau pública de només lectura que fa servir la mateixa web, en pàgines de 1.000 resultats en JSON.
Especialitats formatives Catàleg d'especialitats formatives del SOC: denominació, família i àrea professional, nivell, durada en hores, mòduls formatius i, si escau, certificat de professionalitat associat. Unitat de resultat del mode FPO i taxonomia de famílies i àrees d'aquest mode. API Algolia Mateix mètode, sobre l'índex d'especialitats d'Algolia.
Centres de formació a Catalunya Entitats i centres que imparteixen formació per a l'ocupació a Catalunya: adreça, telèfon, correu i web. Dades de contacte del centre a cada curs del panell de detall del mode FPO. API Algolia Mateix mètode, sobre l'índex de centres d'Algolia.

Catàleg d'Especialitats Formatives del SEPE

sede.sepe.gob.es

Font d'àmbit estatal: el catàleg d'especialitats de la formació en el treball (Llei 3/2023 d'Ocupació i Reial decret 438/2024), que gestiona el Servei Públic d'Ocupació Estatal. Són especialitats com «Tutorització en teleformació» (SSCE22): formació per a l'ocupació, sovint curta, que no forma part dels Graus A–E ni dona cap títol o certificat oficial.

Font Què se n'obté On es fa servir Com s'obté
Especialitats formatives Totes les especialitats vigents (unes 7.500): codi, denominació, família i àrea professional, nivell, hores, modalitat, competència transversal, dates de vigència i si admet aula virtual i tutoria presencial (aquesta darrera es desa però encara no es mostra: el SEPE no explica què vol dir). Pestanya «Especialitats SEPE» del cercador i bloc «També al catàleg estatal del SEPE» sota els resultats d'una cerca. També serveix per classificar les especialitats del mode FPO. API interna El cercador del SEPE carrega el llistat des d'un servei JSON intern, sense registre ni captcha. Es demana sencer en blocs de 2.000 especialitats. Si admeten aula virtual o tutoria presencial s'obté amb dues consultes més, amb els filtres avançats del mateix cercador.
Programa formatiu (PDF) Document oficial de cada especialitat: objectiu, mòduls i hores, requisits d'accés de l'alumnat i del professorat, espais i equipaments. Botó «Programa formatiu (PDF)» de cada especialitat SEPE i, al mode FPO, quan el SOC no n'enllaça cap. Descàrrega a demanda El SEPE només lliura el PDF des del seu formulari. GrausFP el demana la primera vegada que algú l'obre i en guarda una còpia 30 dies.
Entitats de formació Entitats autoritzades a impartir cada especialitat: nom, tipus (presencial o teleformació), província, adreça, telèfon i web. No vol dir que tinguin cap curs obert. El NIF i el titular no es mostren, i el correu només el veu l'administració del web. Botó «Entitats que la imparteixen» de cada especialitat SEPE, al cercador i al mode FPO. Consulta a demanda El SEPE només lliura la llista des del seu formulari. GrausFP la demana la primera vegada que algú l'obre i en guarda una còpia 7 dies.
Contingut del programa i ocupacions De cada programa formatiu: objectiu, mòduls amb les hores, requisits d'accés, hores de tutoria presencial o de presencialitat i «per a què serveix» (vinculacions amb capacitacions professionals). Del cercador del SEPE: les ocupacions relacionades, amb el codi d'ocupació. El text es mostra en castellà, tal com el publica el SEPE. Fitxa de cada especialitat SEPE al cercador, en desplegar-la. Descàrrega periòdica Es llegeixen tots els programes (PDF) i el quadre d'ocupacions de cada especialitat, a poc a poc i fora del servidor del web, i se'n guarda només el text extret. Es repassen sencers cada pocs mesos; entretant, s'hi afegeixen les especialitats noves o que canvien de versió. Si la suma d'hores dels mòduls no quadra amb la del catàleg, els mòduls no es mostren. Si un programa no es pot llegir, la fitxa només ofereix el PDF.

Catàleg de famílies professionals

Les 24 famílies professionals (i les variants històriques del pla anterior) es normalitzen amb una taula de correspondència interna, derivada del catàleg de la Llei Orgànica 3/2022. Serveix per unificar sota un mateix nom les famílies que apareixen amb formats diferents segons la font.

Dades que no provenen de tercers

El compte d'usuari (registre, favorits, alertes i seguiments de centres) es desa en una base de dades pròpia i no es comparteix amb cap tercer. L'Historial d'actualitzacions i l'Observatori es generen a partir dels registres de les actualitzacions periòdiques del mateix cercador.

Amb quina freqüència s'actualitza

El cercador torna a llegir les fonts automàticament un cop per setmana: el catàleg de graus, les fitxes del Ministeri, el catàleg d'especialitats del SEPE i els cursos FPO (SOC, PIMEC, Foment, Cecot i CCOO). L'índex d'ocupacions es regenera un cop al mes, i els centres del Registre Estatal s'actualitzen a demanda des del panell d'administració. Cada actualització queda registrada, amb el detall dels canvis, a l'Historial d'actualitzacions.

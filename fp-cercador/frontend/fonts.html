Fonts de dades

D'on surt tota la informació que mostra el cercador

Totes les dades del cercador provenen de fonts públiques i oficials de l'Administració General de l'Estat. Cap dada s'introdueix manualment: el sistema llegeix automàticament les fonts que es descriuen a continuació i les consolida en un únic índex.

El marc de referència és la Llei Orgànica 3/2022, d'ordenació i integració de la Formació Professional, que estableix els Graus A, B, C, D i E i el catàleg de famílies professionals.

Ministeri d'Educació, Formació Professional i Esports

todofp.es

El portal oficial de la FP a Espanya. En són l'origen el catàleg de títols i certificats, les fitxes tècniques i els documents normatius.

Font Què se n'obté On es fa servir Com s'obté
Cercador de Graus FP Catàleg complet dels Graus A, B i C (pla actual i pla anterior): codi, denominació, família professional, nivell i enllaç a la fitxa oficial. Base del llistat principal del cercador. API JSON Es consulta l'API JSON interna del cercador (buscadorGeneralA, B i C): una petició GET inicial obté les cookies de sessió i després 9 consultes (3 graus × 3 nivells) retornen tots els registres.
Pàgines «Qué estudiar» Cicles formatius (Grau D) — bàsic, mitjà i superior — i cursos d'especialització (Grau E), amb denominació, família i nivell. Graus D i E del llistat principal. Scraping HTML Es descarrega l'HTML de cada pàgina i se'n llegeixen les taules amb BeautifulSoup; la família es dedueix de l'atribut headers de cada cel·la.
Buscador de Certificados de Profesionalidad Dades complementàries dels certificats de pla anterior: durada en hores i cicles formatius equivalents. Fitxa de detall dels Graus C de pla anterior i itinerari cap a Grau D. Formulari POST S'envia el formulari de cerca per POST (/busquedaCP) i se n'analitza l'HTML de resposta; els cicles equivalents surten d'una segona petició POST (/ciclosFP) per a cada certificat.
Documents oficials (repositori DAM) Annexos publicats al BOE / reials decrets (PDF) i suplements Europass en castellà i anglès. Els annexos també es processen per extreure les unitats de competència de cada certificat. Botons de documents a la fitxa de detall i relació entre mòduls (Grau B) i certificats (Grau C) de pla anterior. PDF Els enllaços als PDF es construeixen a partir del codi de cada certificat. Per a la relació entre mòduls i certificats, un script d'execució puntual descarrega els 584 annexos i n'extreu els codis d'unitat de competència amb pdfplumber.
Fitxes dels certificats de Grau C (pla actual) Llista de mòduls professionals de cada certificat de pla actual. Relació entre mòduls (Grau B) i certificats (Grau C) de pla actual, i itinerari cap a Grau D. Scraping HTML Es visita la fitxa web de cada certificat i se'n llegeix la secció «Módulos Profesionales», a 1 petició per segon com a màxim, amb reintents (espera de 5, 15 i 45 s) i comprovació del «Código:» de la pàgina.
Fitxes dels cicles de Grau D Secció «Plan de formación» de cada cicle: mòduls que el componen i codi d'ensenyament. Càlcul de quins Cursos d'Especialització continuen cada certificat de pla actual. Scraping HTML Es visita la fitxa web de cada cicle i se'n llegeix la llista de la secció «Plan de formación», a 1 petició per segon com a màxim i amb reintents.
Seccions «Salidas profesionales» Ocupacions i llocs de treball associats a cada ensenyament (dels PDF dels certificats i de les fitxes dels Graus D i E). Cerca per ocupació. PDF + HTML Certificats de pla anterior: es demana per POST el PDF de llocs de treball i se'n llegeix el text amb pdfplumber. Graus D i E: es llegeix la secció de la fitxa HTML. L'índex es regenera un cop al mes.
Fitxes dels Graus B i dels Graus A (pla anterior) Resultats d'aprenentatge i estàndards de competència de cada Grau B i, per a cada Grau A de pla anterior, el Grau B o els Graus B que el contenen. Panell «En què consisteix» dels Graus A i relació de cada Grau A amb el seu Grau B. Scraping HTML Es visita la fitxa web de cada Grau B (unes 3.000) i de cada Grau A de pla anterior, i se'n llegeixen les llistes d'elements amb codi. Quatre fils en paral·lel (menys de ~2 peticions per segon), amb reintents i comprovació del «Código:» de la pàgina.

Registre Estatal d'Entitats de Formació de la FP

registrosfp.educacion.gob.es

El registre públic dels centres autoritzats per impartir Formació Professional a tot l'Estat.

Font Què se n'obté On es fa servir Com s'obté
Consulta pública d'oferta Centres que imparteixen cada ensenyament (Graus A–E), amb població, província i comunitat autònoma. Panell de centres de cada resultat i seguiment de novetats. API JSON Una petició GET inicial obté la cookie de sessió i després es consulta un endpoint JSON (datosTablaPublico) per a cada ensenyament: unes 1.200 consultes a 1 per segon (~20 min).
Fitxa de centre Adreça web de cada centre, quan consta al registre. Enllaç al web del centre dins el panell de centres. Scraping HTML Primer es dedueix del domini del correu del centre; si no n'hi ha, es llegeix l'HTML de la fitxa del centre (centrorcd), amb esperes si el servidor limita les peticions (HTTP 429).

Servei Públic d'Ocupació de Catalunya (SOC)

serveiocupacio.gencat.cat

Font d'àmbit autonòmic: cobreix únicament l'oferta de formació professional per a l'ocupació (FPO) gestionada per la Generalitat de Catalunya. És un sistema diferent de la FP reglada estatal i no inclou cap altra comunitat autònoma.

Font Què se n'obté On es fa servir Com s'obté
Cursos FPO Cursos de formació per a l'ocupació programats a Catalunya: centre, dates, horari, modalitat, estat d'inscripció i enllaç a la fitxa del SOC. Mode «Cursos FPO (Catalunya)» del cercador i panell de detall de cada especialitat. API Algolia El cercador del SOC funciona amb Algolia, un servei de cerca extern. Es recorre l'índex de cursos sencer amb la clau pública de només lectura que fa servir la mateixa web, en pàgines de 1.000 resultats en JSON.
Especialitats formatives Catàleg d'especialitats formatives del SOC: denominació, família i àrea professional, nivell, durada en hores, mòduls formatius i, si escau, certificat de professionalitat associat. Unitat de resultat del mode FPO i taxonomia de famílies i àrees d'aquest mode. API Algolia Mateix mètode, sobre l'índex d'especialitats d'Algolia.
Centres de formació a Catalunya Entitats i centres que imparteixen formació per a l'ocupació a Catalunya: adreça, telèfon, correu i web. Dades de contacte del centre a cada curs del panell de detall del mode FPO. API Algolia Mateix mètode, sobre l'índex de centres d'Algolia.

PIMEC Formació

pimecformacio.org

Font d'àmbit català: cursos de formació de PIMEC (subvencionats, bonificables i altres). Es llegeixen del cercador de cursos públic de la seva web. Cada curs mostra el tipus tal com el publica PIMEC.

Font Què se n'obté On es fa servir Com s'obté
Cursos de PIMEC Formació Títol, tipus (subvencionat, bonificable, diàleg social o altres), dates, hores, població, modalitat, àrea i enllaç a la fitxa de PIMEC. Mode «Cursos FPO (Catalunya)» del cercador, marcats amb la font PIMEC. Endpoint AJAX Es crida l'endpoint AJAX del cercador de cursos (Drupal), que retorna JSON amb les targetes en HTML. Es pagina fins a trobar una pàgina buida i es fa una passada per àrea, perquè les targetes no l'indiquen.

Foment Formació

fomentformacio.com

Font d'àmbit català: cursos de Foment Formació. Es llegeixen del catàleg públic de la seva web. Foment no publica un tipus per curs, de manera que es mostren com a «Altres».

Font Què se n'obté On es fa servir Com s'obté
Cursos de Foment Formació Títol, edicions (centre, dates, horari, hores i modalitat) i enllaç a la fitxa de Foment. Mode «Cursos FPO (Catalunya)» del cercador, marcats amb la font Foment. Sitemap + HTML Es llegeix el sitemap XML dels cursos (WordPress) i després l'HTML de cada fitxa, on cada edició es compta com un curs.

Cecot Formació

formacio.cecot.org

Patronal amb seu a Terrassa i entitat formadora acreditada. Es llegeix el seu cercador públic de cursos. Els cursos gratuïts es marquen com a «Subvencionat» i els de pagament com a «Altres».

Font Què se n'obté On es fa servir Com s'obté
Cursos de Cecot Títol, dates, hores, modalitat, horari, adreça i enllaç a la fitxa de Cecot. Mode «Cursos FPO (Catalunya)» del cercador, marcats amb la font Cecot. API JSON + HTML Un endpoint JSON públic retorna la llista de cursos; la data de fi, l'horari i l'adreça es llegeixen de l'HTML de la fitxa de cada curs.

Fundació Paco Puerto (CCOO)

fundaciopacopuerto.cat

Entitat formadora de CCOO de Catalunya. Es llegeix el seu catàleg públic de cursos, sense les oposicions ni la formació sindical.

Font Què se n'obté On es fa servir Com s'obté
Cursos de la Fundació Paco Puerto Títol, família, dates, hores, modalitat, horari, localitat i enllaç a la fitxa. Mode «Cursos FPO (Catalunya)» del cercador, marcats amb la font CCOO. API WordPress + HTML La llista surt de l'API REST de WordPress (WooCommerce, /wp-json/wp/v2/product); les dates, hores, modalitat i horari es llegeixen de l'HTML de cada fitxa.

Catàleg de famílies professionals

Les 24 famílies professionals (i les variants històriques del pla anterior) es normalitzen amb una taula de correspondència interna, derivada del catàleg de la Llei Orgànica 3/2022. Serveix per unificar sota un mateix nom les famílies que apareixen amb formats diferents segons la font.

Dades que no provenen de tercers

El compte d'usuari (registre, favorits, alertes i seguiments de centres) es desa en una base de dades pròpia i no es comparteix amb cap tercer. L'Historial d'actualitzacions i l'Observatori es generen a partir dels registres de les actualitzacions periòdiques del mateix cercador.

Amb quina freqüència s'actualitza

El cercador torna a llegir les fonts automàticament un cop per setmana: el catàleg de graus, les fitxes del Ministeri i els cursos FPO (SOC, PIMEC, Foment, Cecot i CCOO). L'índex d'ocupacions es regenera un cop al mes, i els centres del Registre Estatal s'actualitzen a demanda des del panell d'administració. Cada actualització queda registrada, amb el detall dels canvis, a l'Historial d'actualitzacions.
